# 科目A-1ラボ

情報処理技術者試験の高度試験・情報処理安全確保支援士試験の科目A-1（旧 午前Ⅰ）の範囲を、
短い本文と図で積み上げる教科書と、計算や処理の流れを1ステップずつ追う図解で学ぶサイトです。
IPA（情報処理推進機構）とは関係のない、非公式の学習サイトです。

## 内容

| | 内容 |
| --- | --- |
| 教科書（`/book/<章>`） | テクノロジ系・マネジメント系・ストラテジ系の全分野を19章で。節ごとに本文と図を積み重ね、章の最後に「あわせて押さえる用語」と確認問題（4択） |
| 図解（`/walk/<図解>`） | 進数の変換、確率、ソート、パイプライン、稼働率、ページ置換、正規化、サブネット、クリティカルパス、EVM、損益分岐点などを1ステップずつ。図の見かたとひとことでの説明付き。図は描かれる順に動き（矢印が伸びる、帯が時間どおりに伸びる、線が描かれる）、自動で再生もできる |
| 用語（`/terms`） | 文中の点線の付いた用語を押すと、意味と、その用語が出てくる章や図解が表示される |

章と図解は `src/content/`（分野ごとのフォルダ）に、用語は `src/glossary/` にあります。
図解の「図の見かた」と「ひとことで」は `src/content/plain.ts` にまとめています。図の動きは `src/styles.css` の「図の動き」にあり、動きを減らす設定の利用者には動かしません。

一部の図解には、身近なものの絵と短いせりふで流れを見せる「動く図解（紙芝居）」があります（`src/scenes/`）。1つの図解に1つの場面（Scene）を作り、`src/scenes/index.ts` の `SCENES` に図解の ID で登録します。場面は、せりふ（Beat）の並びと、場面の番号を受け取って絵を描く `Stage` でできています。再生中・一時停止中・終わりの表示と、場面ごとの進み具合のバーは `ScenePlayer` が受け持ちます。
テストで、図の部品の参照、図解へのリンク、用語の出てくる場所、4択の正解の偏りなどを確かめています。

## 開発

Node.js 22 と、corepack で有効にした pnpm を使います。

```sh
corepack enable
pnpm install
pnpm dev        # 開発用サーバ
pnpm verify     # 型チェック・テスト・ビルド・セキュリティチェックをまとめて実行
```

## セキュリティの設計

| 対策 | 防ぐもの |
| --- | --- |
| サーバ・データベース・ログインのない静的サイト | サーバの脆弱性の悪用、情報漏えい |
| Reactの自動エスケープだけで表示し、`dangerouslySetInnerHTML` などを禁止（CIで検査） | XSS |
| CSPで、スクリプトもスタイルもフォントも自サイトからだけ読み込む | XSS、外部CDNの改ざん |
| HSTS、`frame-ancestors 'none'`、`nosniff` などのヘッダ（`public/_headers`） | 中間者攻撃、クリックジャッキング、MIMEタイプの誤認 |
| 公開から7日未満のパッケージを入れない、許可したもの以外のインストールスクリプトを止める（`pnpm-workspace.yaml`） | サプライチェーン攻撃 |
| GitHub Actions をコミットSHAで固定し、権限は読み取りだけ | CIの乗っ取り |
| `security.txt` と `SECURITY.md` で連絡窓口を用意 | 脆弱性が報告されないまま放置されること |
